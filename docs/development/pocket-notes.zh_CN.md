# 多页便笺

AI Passport 中文五页应用：原神便笺、Codex 额度、威联通状态、通过 Home Assistant
接入的米家遥控，以及电脑资源监控。默认启动新界面，不进入上游硬件测试菜单；驱动和硬件常量仍由
BSP 提供。

开发交接入口：[源码导航与专属页清单](pocket-notes-page-development.zh_CN.md)、
[已实现接口规范](pocket-notes-protocol.zh_CN.md)、
[开发与验收记录](pocket-notes-development-log.zh_CN.md)。

## 页面与按键

| 页面 | 信息与操作 |
| --- | --- |
| 原神 | 树脂与恢复时间、委托、奖励领取状态、派遣、洞天宝钱；国服扫码登录及手机人工安全验证 |
| Codex | 主次额度剩余比例、重置时间、余额、重置卡数量；接口明细完整时显示最早到期日期，不兑换重置卡 |
| 威联通 | 接口报告的 CPU 平均负载、内存占用、最大固定存储卷占用和可用容量、主机运行时间、连接状态 |
| 米家 | 分页读取 HA 的 `xiaomi_home`/`xiaomi_miio` 集成功能项，查看状态、预览操作并明确确认 |
| 电脑监控 | 从 CPU、GPU 占用/温度、内存、显存、系统盘占用/可用空间、开机时长、连接状态中勾选并自动分页，共用额度助手配对 |

普通浏览时上下键翻页，确定键刷新；识别到上下键双击时翻两页。每页手动刷新
最短间隔 30 秒。停留时原神每五分钟、Codex 每分钟、NAS/HA/电脑监控每 30 秒更新。
等待 Wi-Fi 或校时时会更快重试；缺少配置或认证失败时暂停自动请求。

原神页长按确定生成登录二维码，用国服米游社 App 扫码并由本人确认。需要安全
验证时，长按确定改为创建人工验证会话：用同一局域网的手机扫码，亲自完成验证。
会话五分钟失效，切换页面取消。账号凭据留在板端，网页只接收公开验证码配置；
只有真实便笺查询成功才恢复同步。登录选择接口标记角色或首个国服角色。
小组件响应不标明角色 UID，有多个角色时请核对官方小组件关联角色。
未实现国际服 HoYoLAB 登录，不会自动破解验证码。

米家页按确定进入功能项选择，上下键选择；再按确定进入操作选择，上下键选动作。
确定预览目标和参数，再按一次确定才提交。上下键取消预览，长按确定恢复普通
翻页。长按上可刷新米家功能列表。预览 30 秒失效，状态过期、目标变化、已有指令待处理时禁止重复提交。
指令已被接受但状态读取失败时，显示“已提交，状态未确认”，不会自动重试。

在集成暴露且设备支持的前提下，提供电源、灯亮度、风速、空调温度、窗帘、
清扫/暂停/回充、选项与数值实体、按钮、场景/脚本及基础媒体操作。
其他类型保持只读。这不等于复刻米家全部专有功能或保证全部设备类别可用；
一台物理设备可能显示多个 HA 功能项，实际兼容性须逐设备测试。

## 私密设置

新版电脑助手入口是 [Codex-Assistant.cmd](../../Codex-Assistant.cmd)，界面主标题为
“同步额度与电脑资源”，窗口标题仍叫“Codex 额度助手”。这是同一个服务，不需要再运行
另一款电脑监控助手。从原项目目录重开可以沿用配对；新解压的副本有独立的私密配对状态。

电脑监控复用现有电脑助手和配对。已经配对过时，关闭并重新打开更新后的助手一次，
不用重新设置或配对。即使 Codex 认证/联网暂时不可用，电脑资源仍可读取。
长按下键扫码，在“电脑监控”卡片勾选指标并保存，超过六项自动分页，设备重启后生效；未选的行隐藏。
默认显示 CPU、GPU 占用、GPU 温度、内存、系统盘占用和连接状态。选择保存在独立 NVS
键中，不改变版本 1 的设置结构，保留原神登录、Wi-Fi 与电脑配对，不用重新登录或 USB 设置。

带鉴权的 `GET /v1/pc` 只读取汇总计数器，不读取进程名称或文件列表。
CPU 是相邻采样间隔的平均占用；系统盘指 Windows 所在盘，不表示全部磁盘。
GPU 占用、摄氏温度和显存占用来自第一张 NVIDIA 显卡（驱动索引 0），使用已安装驱动的
`nvidia-smi` 只读查询，两秒超时、隐藏窗口。不额外安装 Python 包、特权传感器驱动或
硬件监控服务。GPU 不支持或读取失败时显示“不可用”，不伪造为零，也不把旧温度当新数据；
CPU/内存仍可显示。尚未实现 AMD/Intel GPU 传感器、进程列表。NVIDIA 利用率与
任务管理器取最忙引擎的百分比可能不同，见 [NVIDIA 查询说明](https://docs.nvidia.com/deploy/nvidia-smi/index.html)。
电脑监控目前仅支持 Windows，断连时
在内存中保留旧值及原更新时间、标记过期，不额外写 Flash 缓存。
Passport 沿用同一套界面对象和网络任务，不增加并行网络请求。

### 手机设置（推荐）

1. 刷入本固件后，首次开机没有 Wi-Fi 设置时，屏幕会显示带密码的
   `Passport-XXXX` 设置热点二维码。用手机相机扫码连接；手机提示没有互联网时，
   选择保持连接。
2. 在设备按一次确定，切换成网页二维码，再用手机扫码打开。填写家里的
   2.4 GHz Wi-Fi 名称和密码，保存后设备重启。手机切回家庭 Wi-Fi，
   查看设备屏幕确认实际联网。
3. 以后任何页面长按下键即可打开统一设置。设备已经联网时，在同一家庭网络
   直接扫码进入网页，不需要 USB 设置。长按确定退出；每次设置十分钟后关闭。
4. 原神直接在设备扫码登录。Codex 在电脑双击
   [`Codex-Assistant.cmd`](../../Codex-Assistant.cmd)，点击启动，把助手显示的
   电脑地址和六位配对码填在手机 Codex 卡片。配对码两分钟有效、最多尝试五次、
   只能使用一次。助手自动使用电脑现有代理。
5. NAS 卡片已填 `192.168.1.250`，只需先在威联通开启只读 SNMP，然后填写团体名。
   米家卡片在安装并登录 HA/Xiaomi Home 后，填写 HA 地址和访问令牌。
   这两项都可以先跳过，以后再完成。

每张卡片只保存自己的字段并重启设备，保留其他设置。密码/令牌留空保留原值，
Wi-Fi 的开放网络有单独选项。网页不会返回已保存的私密值。设置会话要求二维码中
的随机访问密钥、同源写入及准确的本机地址。临时 WPA2 热点只在初次设置或恢复时
使用，平常浏览使用 STA 模式。开机三十秒仍未联网时，自动提供一次恢复设置。
设置期间暂停业务请求以控制内存占用。不依赖手机自动弹出配网页，请按上述步骤扫码。

### 可选的 USB 备用方式

Windows 设置 Wi-Fi 时，双击项目中的 [`WiFi-Setup.cmd`](../../WiFi-Setup.cmd)。
打开设备电源并用 USB 数据线连接电脑，选择对应串口，填写 2.4 GHz Wi-Fi 名称和
密码，点击“保存到设备”即可。窗口只更新 Wi-Fi，保留其他设备设置，不在电脑上
写入密码文件。首次使用需先刷入多页便笺固件。“设置已保存”不代表 Wi-Fi 已连接，
重启后请查看设备屏幕确认。启动器自动使用已安装的 ESP-IDF 5.5 Python 环境，
不需要手动激活环境或编辑 JSON。

其他服务或命令行设置方式如下：

使用 2.4 GHz Wi-Fi，并确保可访问电脑、NAS、HA 的局域网地址。若使用进阶的 USB
备用设置，可创建私密模板，不会覆盖已有文件：

```text
python tools/configure_pocket.py --create-template
```

在本地编辑 `build/private/device.json`，填写 Wi-Fi 凭据、`companion_url` 中的
电脑局域网地址及端口、`nas_community` 中的只读 SNMPv2c 团体名，以及
`home_url`/`home_token` 中的 HA 地址和访问令牌。NAS 已选地址为
`192.168.1.250`。可选项留空时对应页面未配置；不要通过聊天发送凭据，也不要
提交私密配置文件。

启动电脑额度助手，复用已安装 Codex CLI 的现有登录：

```text
python tools/codex_companion.py --bind <PC_LAN_IP> --proxy http://127.0.0.1:7890
```

替换电脑局域网地址；7890 为本机已发现的现有代理端口，换电脑时按实际值填写。
省略 `--bind` 则只监听本机回环。助手仅提供带鉴权的 `GET /v1/codex`。
独立只读配对令牌位于 `build/private/companion.token`，配置指定
`companion_url` 且没有令牌时，USB 工具自动读取它。需要时在电脑防火墙允许
私有局域网访问；工具不修改防火墙或路由器，也不向板端复制账号凭据。

先检查，再使用实际端口应用配置：

```text
python tools/configure_pocket.py --dry-run
python tools/configure_pocket.py --port <DEVICE_PORT>
```

应用配置需要 `pyserial`，已包含在激活的 ESP-IDF 环境中。工具保存设置、等待
确认并重启应用，不烧录固件，不回显私密值及串口输入。板端设置存入 NVS，
本应用未加密。私密文件位于已忽略的 `build/`，不要分发这些文件或已配置设备
的 Flash 内容。

成功值最多每页五分钟写一次缓存，重启后标记过期并保留原更新时间。断网保留
最后成功值，缺失字段显示 `--`。示例账号/设备值只存在于主机渲染测试，不在
实际应用中。

## NAS、HA 与长期独立运行

NAS 为 `192.168.1.250` 的 TS-212P3，实际 QTS 版本未核实。请启用专用只读
SNMPv2c 团体名。客户端使用 HOST-RESOURCES-MIB 的 CPU、存储表及主机运行
时间，限制遍历次数。存储显示最大的固定卷，不随意累加各存储池；不支持的指标
保持不可用，需与实际 NAS 对比。

已确认通过 HA 接入米家。小米官方集成源码及云接口授权限于 HA 用途，因此未
直接移植到独立固件。应在 HA 完成小米登录，板端调用 HA 公开 REST API。
参见 [HA 部署说明](../../services/homeassistant/README.zh_CN.md)。TS-212P3
只有 1 GB 内存，尚未确认适合承载新增服务；先用现有电脑或合适的 Linux 主机，
不默认旧 NAS 能运行整套服务。

电脑采集助手须持续运行才能更新 Codex。旁路由只解决联网，采集仍需要主机。
未为 AC9 选择或烧录固件，硬件版本仍未知。以后可迁移采集程序，但需先核实
新主机的 Codex 和运行环境兼容性。

## 验证与交付

原神失败时，诊断固件会显示固定请求阶段，以及 `H`（HTTP 状态）、`A`（服务
返回码）或 `E`（十六进制 ESP 错误）。USB 警告日志额外记录阶段编号、错误和当前
堆内存大小，不输出请求 URL、Cookie、账号信息或二维码票据。这用于定位故障，
不代表已修复登录失败。用户随后确认设备校验阶段报 `E101`（`ESP_ERR_NO_MEM`）。
HTTP 现按请求头实际大小分配发送缓冲，按已知响应长度分配响应缓冲，分块响应按需
增长；保留 12 KiB 响应上限、证书校验与 TLS 记录限制。主机故障注入覆盖短响应、
长验证码头、分块/超长/截断响应及增长分配失败。2026-11-07，用户在镜像 SHA-256
`0e57c534f35868350888550db78b56bc3fd0a3af4e540fa7c0e1ad519d83dcad`
仅更新应用后确认扫码登录和配置成功，所反馈的 E101 已恢复。长时间稳定性及便笺
数值准确性未独立测量。

新界面使用[资源说明](../../assets/README.zh_CN.md)中的思源黑体，准确清单
21,352 字符。静态检查覆盖固定文案和位图边界；主机渲染通过真实 LVGL 查询
全部清单字符，并检查确定缺失的表情。动态文字超出范围时明确提示。主机预览
标明模拟测试数据，LCD 的颜色、裁切和可读性仍需实屏验证。

ESP-IDF 5.5.3 下运行 `tools/validate.sh`。完整门禁保留可从 `0x0` 写入的
`build/FoloToy-AI-Passport-full.bin`，以及按镜像哈希归档的 ELF/MAP。
Windows 可能需要英文路径构建副本及兼容 shell；本次临时处理不修改全局代理、
Git、兼容性或缓存设置。

上板验收需覆盖启动、按键、中文、登录/人工验证、Wi-Fi 重连、电脑睡眠/重启、
NAS 指标对比及逐设备米家操作。编译不代表硬件验收。合并刷写可能重置设置，
写入前须明确确认；不以全片擦除或原固件回读为前提。

一手资料：[Codex App Server](https://learn.chatgpt.com/docs/app-server)、
[HOST-RESOURCES-MIB](https://www.rfc-editor.org/rfc/rfc2790)、
[威联通 SNMP](https://www.qnap.com/de-de/how-to/faq/article/how-to-get-the-list-of-messages-send-by-the-snmp-server)、
[小米集成](https://github.com/XiaoMi/ha_xiaomi_home)、
[HA REST API](https://developers.home-assistant.io/docs/api/rest/)。

## 页面顺序与启停

长按下键扫码，在“页面顺序与启停”卡片用上移/下移调整顺序，取消勾选可停用页面。
至少保留一页。保存重启后首先显示排在最前的启用页；上下翻页（含双击）跳过停用页，
分页点按可见页面的数量和顺序显示。停用页不自动请求，保留原账号与配置。
在任一启用页长按下键仍可进入设置重新启用。旧设备未设置时沿用原五页默认顺序。
偏好保存为独立 NVS 字符串，版本 1 凭据结构与缓存快照布局不变。


## 息屏与扩展监控

默认闲置 60 秒关闭背光；手机设置可选不自动息屏、30/60/120/300 秒。首次按键只唤醒，
其长按/双击事件也会被抑制，稍候再操作。设置、登录二维码与遥控操作期间不自动息屏。
Wi-Fi 和当前页刷新继续运行，这不是深度休眠。普通非米家页长按上键可息屏；米家原有
长按上刷新保留。手机“立即息屏”按钮不重启设备，也不结束设置会话。

电脑目录扩为 23 项：原九项加内存已用/可用/总量、显存已用/可用/总量、GPU 功耗/
风扇/图形频率、CPU 频率、磁盘读写与网络收发速率。关闭旧助手，从原目录重开可沿用配对。
不增加 Python 包。可选性能项来自 Windows PDH；权限不足或计数器不可用时显示不可用。
磁盘速率汇总物理磁盘，而容量仍指系统盘。网络汇总接口，虚拟/VPN 网卡可能重复计数。
CPU 为计数器报告的 MHz；GPU 风扇为驱动百分比，不是转速。未提供 CPU 温度。
容量单位 GiB，速率 KiB/s 或 MiB/s；速率/CPU 占用为请求间隔平均值，不是瞬时分析器。
GPU 新增项仍只读取驱动索引 0。

电脑设置勾选超过六项会生成子页，上下键先遍历电脑子页，再进入下一启用应用页，
反向进入电脑页时显示末个子页。标题显示电脑子页页码，底部分页点仍代表启用的应用页。
原有六项选择继续保留。RAM 仅保存一份紧凑数值样本，不增加屏幕对象、任务或指标 Flash
缓存。米家调研单独见[八键方案调研](mihome-eight-key-research.zh_CN.md)。

## 屏幕亮度

长按下键扫码，在“屏幕亮度”中选择 10%–100%，点击“应用并保存”。默认沿用 75%。
保存后由 UI 循环应用，无需重启，重启后保留；拖动仅更新手机上的百分比，不写 Flash。
息屏时修改亮度仍保持息屏，下次亮屏恢复所选值。0 保留给息屏。百分比对应 PWM
占空比，实际耗电及续航变化需真机测量。

已记录短按左侧电源键切换息屏/亮屏需求，但尚未实现。仓库规格将其描述为独立硬件
电源键，引脚表/BSP 仅暴露上、下、确定三键，未定义电源键 GPIO 或可读电源控制器
接口。这些资料不足以实现侧键，也不足以断言所有硬件版本都没有可读信号；仍需确认
电气接口。现有功能键唤醒仍可用。

## 设备端屏幕设置

在普通业务页概览双击确定进入“屏幕设置”。上下键选择“屏幕亮度”“自动息屏”或
“返回”，确定进入调整；上键增加、下键减少。亮度每次调整 5 个百分点，范围
10..100；息屏可选关闭、30/60/120/300 秒。再按确定保存。亮度即时预览，调整时
不写 Flash；编辑时长按确定取消并恢复已保存值，列表中长按确定退出，也可选返回后
按确定。值未改变时不写 Flash。保存中显示进度并暂时忽略菜单指令；失败恢复原值，
可重试。菜单打开期间保持亮屏。

手机和设备端共用持久化偏好。原神长按确定登录、长按下键手机设置入口保留；扫码
登录、手机设置、米家设备/操作流程中不开启本菜单。刚唤醒时仍先消耗首次唤醒手势。
