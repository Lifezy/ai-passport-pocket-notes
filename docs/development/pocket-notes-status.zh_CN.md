# 多页便笺 v0.1.0：当前状态与已知问题

更新于 2026-11-09。`VERSION` 标识首次公开的**源码版本**，不改变 ESP-IDF 版本，也不
追溯修改已经刷入的开发固件版本名。此文件不表示已创建标签或 GitHub Release。

## v0.1.0 已包含

- 原神、Codex、NAS、Home Assistant、电脑监控五个业务页。
- 手机 Wi-Fi/服务配置、限时二维码设置会话和电脑配对。
- 23 项电脑指标，每六项自动分页，以及业务页排序和启停。
- 手机及本机亮度/息屏时间设置，可关闭自动息屏。
- 完整 BSP/应用源码、字体及授权、Skill、主机测试、接口规范与页面开发指南。

## 未解决或不支持

| 项目 | 当前表现或边界 |
| --- | --- |
| 左侧电源键短按 | 尚未实现；公开板级定义未提供已确认的可读信号/控制器，不能猜测 GPIO |
| 唤醒后快速操作 | 首次唤醒手势被消耗，松手后还有 500 毫秒保护。快速连续按键可能延长抑制时间，感觉不灵敏 |
| 部分界面不会自动息屏 | 手机设置、登录二维码、米家设备/操作流程保持亮屏；尤其米家列表即使无后续操作也持续亮屏 |
| HA/米家覆盖 | 需另行部署 HA 并逐设备验证；尚未实现原生米家八键设备注册 |
| GPU/温度覆盖 | 仅 NVIDIA 驱动索引 0；未实现 AMD/Intel GPU 传感器、显卡选择及 CPU 温度，缺失值显示不可用 |
| 聚合监控口径 | CPU/速率是采样间隔平均值；磁盘吞吐汇总物理盘，容量仍指系统盘；虚拟/VPN 网卡可能重复计数 |
| Codex 字段/联网 | 使用接收方自己的已登录 CLI/App Server 和电脑网络；不支持的余额/卡字段显示不可用，未实现兑换卡或改变额度的操作 |
| 原神兼容 | 仅国服扫码；内部上游接口可能变化或要求人工安全验证，未实现国际服登录和自动破解验证码 |
| 存储/安全 | 应用 NVS 未加密；完整合并刷写可能覆盖设置，保留配置需核对分区并更新正确组件 |

上述是当前限制或已知交互问题，不能当作已完成能力。反馈问题可提供现象、复现步骤、
固件/ELF 身份及脱敏错误码，不要上传 Cookie、配对令牌或私密二维码内容。

## 遇到并处理的问题

| 问题 | 修改及证据 |
| --- | --- |
| 原神二维码在 1–2 秒内设备校验 E101 | 诊断定位为指纹准备阶段 `ESP_ERR_NO_MEM`；HTTP 按实际请求/响应大小有界分配，保留证书校验；用户确认扫码登录和配置成功 |
| 电脑显示固定且项数有限 | 增加保存指标选择、可选 NVIDIA/PDH 字段和六行子页，不扩大持久化的六行快照 |
| 页面顺序及启用固定 | 新增独立 NVS 偏好；用户对排序、停用、重启的有限验收反馈正常 |
| 缺少息屏和亮度设置 | 加入背光闲置/手动控制、PWM 亮度持久化及本机菜单，工作任务负责保存；用户确认菜单、亮度预览/保存、取消及不自动息屏正常 |
| 启动配置占用栈空间 | 将临时 2,464 字节配置副本改为短生命周期堆分配；板上栈/堆峰值仍需测量 |
| Windows 构建子进程无法启动 | 开发电脑将 `cmd.exe` 设置为管理员兼容运行；使用仅当前进程的 `RunAsInvoker` 完成构建，未修改全局注册表。这是特定环境处理，不是普通安装要求 |
